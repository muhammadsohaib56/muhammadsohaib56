## Selected Projects

### 🔧 UpFix — AI-Powered RAG Device Repair Assistant
`Feb 2026 – Present`

A diagnostic chat assistant grounded in device repair knowledge, built on **LangChain**, **GPT-4o-mini**, and **Pinecone**.

- Ingestion pipeline converting CSV knowledge bases into chunked documents, embedded with `text-embedding-3-small` and batch-upserted to Pinecone for scalable semantic retrieval
- Runtime query embedding with top-k similarity search, so responses stay anchored to retrieved repair documentation rather than model priors
- Multi-turn context via `ConversationBufferWindowMemory` and structured system prompts, served through a **FastAPI** backend

> `LangChain` · `OpenAI` · `Pinecone` · `FastAPI` · `RAG`

---

### 🎬 ReThread-AI — Video Enhancement & Repurposing System
`Aug 2025`

An automated pipeline that turns long-form video into distribution-ready clips.

- Automated B-roll integration, dynamic reframing across multiple aspect ratios, and AI-generated hooks to lift viewer retention
- Audio cleanup layer: noise removal, silence trimming, and profanity filtering for content compliance
- Sentiment detection models segmenting footage into emotion-based clips for targeted distribution

> `YOLO` · `FFmpeg` · `Gemini 2.5 Flash` · `ElevenLabs` · `Pexels API`

### 📊 Intelligent Project Management System (PMS)
`Oct 2025`

Multimodal analytics over real project data — ingesting structured JSON from **AWS S3** covering projects, teams, tasks, client documents, and chat history.

- Analytics pipeline scoring project health, risk, team performance, task progress, and requirement gaps

- Multimodal processing for transcription, OCR, and NLP across video, audio, and report attachments
